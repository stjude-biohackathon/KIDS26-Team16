# 🏥 Clinical Notes Classifier
###Inspired by St. Jude Children's Research Hospital's published LLM research on survivor symptom classification
## What this does
This AI tool analyzes clinical notes from childhood cancer 
survivors and classifies symptom severity using LLM technology.

## Features
- 📋 Single note analyzer
- 🔍 Patient search by name or disease
- 📈 Disease pattern analysis with charts

## Tech Stack
- Python
- Streamlit
- Groq LLM (llama-3.3-70b)
- Pandas

## How to run
1. Clone this repo
2. Install requirements: pip install -r requirements.txt
3. Add your GROQ_API_KEY to .env file
4. Run: streamlit run app.py
